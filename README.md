# Olist E-Commerce Business Analysis

Business analytics project exploring sales performance, delivery logistics, and customer satisfaction using Olist's Brazilian e-commerce dataset.

## Business Questions
1. Which product categories drive the most revenue vs. order volume?
2. How does delivery delay affect customer review scores?
3. Which states have the worst delivery performance?

## Data
Source: [Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (Kaggle)
Not included in this repo — download separately and place CSVs in a `data/` folder, then run `sql/01_load_data.py` to build the SQLite database.
